# Audit A: core CRM pages, desktop 1440x900 (live, https://pulse-crm-weld.vercel.app)

- Date: 2026-10-01. The browser rendered the app in dark mode. Browser local time was Asia/Dhaka (UTC+6), 02:20 on Oct 1, which was still Sep 30 in UTC.
- Strictly read-only. I did not submit, save, generate or run anything. Filters were cancelled, not applied. On the AI Insights tab I only viewed the empty state and did not click Generate.
- Tab note: I first worked in tab-15. It navigated to `/dashboard/settings?tab=ai` by itself twice. tab-18 did the same once, with no action from me. After I hooked pushState, it did not happen again. The most likely cause is another auditor's action landing on my tab, so this is not listed as a finding.
- Console: the only errors on every page were the Supabase "Lock broken by another request" AbortErrors, which the brief says to ignore. There were 150+ in about 10 minutes. I also hooked console.error, onerror and unhandledrejection, and they caught nothing else.
- Network: no 4xx or 5xx responses from any page. Every resource status was 200. The only ERR_ABORTED entries were cancelled route prefetches.
